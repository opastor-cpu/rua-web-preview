# RUA Perú · Nodo UNSA Arequipa — vista de prueba

Rediseño responsive de la web de RUA, publicado como una versión de prueba para revisión en celulares y escritorio.

**Ver la web:** https://opastor-cpu.github.io/rua-web-preview/

Este repositorio es una copia de trabajo para revisar el diseño. El sitio original está en https://lauracadillo.github.io/RUA/ y no se modifica con esta publicación.

## Publicación

GitHub Pages publica la raíz de la rama `main`. No requiere compilación. Las páginas, estilos, JavaScript y fotografías se encuentran en este repositorio. Las actualizaciones de `main` se publican automáticamente.

## Contenido

- Inicio, Nosotros, Nuestra acción y Participa.
- Menú responsive, filtros de historias y preguntas frecuentes.
- Preparación local de mensajes y enlaces oficiales de contacto. No se envían ni almacenan datos desde el formulario.
- Paisajes provisionales de Arequipa con atribución y licencia en `creditos.html`.
- Historias vinculadas a fuentes institucionales de la UNSA.

Pendientes editoriales: fotografías propias de RUA, información del equipo, convocatorias actuales y datos oficiales de colaboración. No se incluyen estadísticas, integrantes ni cuentas bancarias ficticias.

La vista de prueba solicita a los buscadores que no la indexen. Es pública y accesible mediante el enlace; esta indicación no es un control de acceso.
